## 🔍 Key Insights
- Urban neighborhoods have the highest average price (178K AED)
  compared to Rural (177K) and Suburb (176K)
- Properties with 5 bedrooms show highest listing concentration
  in urban areas
- Price trend shows consistent fluctuation since 1950 with
  average staying between 175K–180K AED
- Budget category dominates listing types across all neighborhoods
- Suburb areas offer best value — slightly lower prices with
  similar property sizes

## 💡 Investment Recommendations
- Urban properties command premium prices — best for high-end investment
- Suburb properties offer best value for mid-range buyers
- 3-4 bedroom properties show most balanced supply across all areas
- Price per sqft is consistent at 103 AED across neighborhoods
